# Hamza Diyagh — Digital Dentistry Portfolio

A cinematic Next.js portfolio concept with a “designing itself” intro sequence, animated typography, scroll reveals, interactive project panels, a custom titanium implant illustration, and responsive layouts.

## Run locally

1. Install Node.js 20 or newer.
2. Open this folder in VS Code / terminal.
3. Run:

```bash
npm install
npm run dev
```

4. Visit http://localhost:3000

## Customize

- Main page content: `app/page.tsx`
- Colors, layout and animations: `app/globals.css`
- Site title and metadata: `app/layout.tsx`

## Before publishing

- Replace the abstract project artwork with your own dental case images (with permission and no patient-identifying details).
- Replace the LinkedIn link with your exact profile URL if needed.
- Add your portrait and preferred logo in `public/` if you want them included.
- Review all certification titles and dates against your original certificates.

The portfolio content was transcribed from the public website hamzadiyagh.com as available on 6 November 2026. The current page lists 11 certificate entries; verify whether there is another certificate to add.
